## 4. بخش MCP کتاب

در بخش MCP با این اجزا آشنا شده‌ام:

- **MCP Host:** محیط اصلی تعامل با کاربر و مدل زبانی.
- **MCP Client:** ارتباط بین Host و MCP Server.
- **MCP Server:** ارائه ابزارها و قابلیت‌ها به Client.
- **Tools:** توابعی که مدل می‌تواند درخواست اجرای آن‌ها را بدهد.
- **Stdio:** روشی برای ارتباط فرایندها از طریق ورودی و خروجی استاندارد.
- **Streamable HTTP:** روش دیگر ارتباط با MCP Server از طریق HTTP.

برای تمرین فعلی از ارتباط Stdio استفاده می‌کنیم.

قبلاً سرور آماده DuckDuckGo MCP را با MCP Inspector آزمایش کردم و سپس سرور MCP اختصاصی خودم را ساختم.

## 5. فایل mcp_server.py

این فایل سرور MCP اختصاصی پروژه است.

```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("KumoView Search Server")


@mcp.tool()
def search_web(query: str, max_results: int = 5) -> list[dict]:
    """Search the web using DuckDuckGo and return relevant results."""
    from ddgs import DDGS

    with DDGS() as ddgs:
        results = ddgs.text(
            query,
            max_results=max_results,
        )
        return list(results)


if __name__ == "__main__":
    mcp.run(transport="stdio")
```

### منطق این فایل

1. `FastMCP` یک سرور MCP می‌سازد.
2. دکوراتور `@mcp.tool()` تابع `search_web` را به‌عنوان ابزار معرفی می‌کند.
3. تابع با استفاده از DDGS در وب جست‌وجو می‌کند.
4. نتایج جست‌وجو را به‌صورت فهرستی از دیکشنری‌ها برمی‌گرداند.
5. `mcp.run(transport="stdio")` سرور را برای ارتباط با Client اجرا می‌کند.

### وضعیت

این فایل با MCP Inspector آزمایش شده است. ابزار `search_web` شناسایی شده و جست‌وجو موفق بوده است.

## 6. فایل mcp_client.py

این فایل برای آزمایش مستقیم ارتباط MCP Client با MCP Server ساخته شده است.

وظایف آن:

1. اجرای سرور MCP از طریق `uv`.
2. ایجاد ارتباط Stdio.
3. ساخت `ClientSession`.
4. اجرای `session.initialize()`.
5. دریافت ابزارها با `session.list_tools()`.
6. فراخوانی ابزار با `session.call_tool()`.
7. نمایش نتایج جست‌وجو.

این فایل با موفقیت اجرا شده و توانسته ابزار `search_web` را پیدا کند و نتایج جست‌وجو را دریافت کند.

دستور اجرا:

`uv run python mcp_client.py`

این فایل را نگه می‌داریم؛ چون برای آزمایش مستقل ارتباط MCP مفید است.

## 7. فایل mcp_agent.py

این فایل مرحله مهم فعلی پروژه است: اتصال مدل زبانی به ابزار MCP و ساخت یک ایجنت واقعی با حلقه تصمیم‌گیری.

اجزای اصلی:

### الف) بارگذاری تنظیمات

```python
load_dotenv()

MODEL_NAME = "openai/gemini-2.5-flash"
API_BASE = "https://1xai.ir/v1"
API_KEY = os.getenv("XAI_1_API_KEY")
```

کلید API از `.env` خوانده می‌شود.

### ب) تبدیل ابزارهای MCP به قالب موردنیاز مدل

تابع:

`convert_mcp_tools_to_llm_tools(mcp_tools)`

تعریف ابزارهایی را که MCP Server ارائه کرده است به قالب Tool Calling موردنیاز LiteLLM تبدیل می‌کند.

اطلاعات هر ابزار شامل نام، توضیحات و `inputSchema` است.

### ج) اتصال به سرور MCP

در تابع `main()`:

- اطلاعات اجرای سرور در `StdioServerParameters` تعریف می‌شود.
- `stdio_client()` ارتباط را برقرار می‌کند.
- `ClientSession` نشست MCP را مدیریت می‌کند.
- `session.initialize()` ارتباط را راه‌اندازی می‌کند.
- `session.list_tools()` ابزارهای موجود را دریافت می‌کند.

### د) تعریف پیام اولیه

مدل با یک درخواست شروع می‌کند:

Find the latest artificial intelligence news using web search, then summarize the three most relevant results.

این پیام در فهرست `messages` قرار می‌گیرد.

### هـ) حلقه ایجنت

برنامه با استفاده از `acompletion()` از مدل پاسخ می‌گیرد.

اگر مدل Tool Call تولید کند:

1. پیام مدل به `messages` اضافه می‌شود.
2. نام ابزار و آرگومان‌های آن استخراج می‌شوند.
3. آرگومان‌ها با `json.loads()` به داده Python تبدیل می‌شوند.
4. ابزار با `session.call_tool()` اجرا می‌شود.
5. نتیجه ابزار به‌صورت پیام `role="tool"` به مکالمه اضافه می‌شود.
6. حلقه دوباره از مدل پاسخ می‌گیرد.

اگر مدل Tool Call نداشته باشد، پاسخ نهایی چاپ می‌شود و تابع با `return` پایان می‌یابد.

### و) محدودیت تعداد مراحل

در نسخه فعلی:

`MAX_AGENT_STEPS = 5`

حلقه حداکثر پنج درخواست معمول از مدل را اجرا می‌کند.

اگر این تعداد تمام شود و مدل هنوز ابزار فراخوانی کرده باشد، برنامه یک درخواست نهایی دیگر با `tool_choice="none"` می‌فرستد تا مدل نتایج موجود را جمع‌بندی کند.

در این حالت تعداد درخواست‌های مدل می‌تواند از پنج بیشتر شود؛ پنج، سقف مراحل حلقه اصلی است، نه کل درخواست‌های مدل.
