# وضعیت ارتقای کامپیوتر و آماده‌سازی Docker

## ۱. مشخصات فعلی سیستم
- مادربرد: ASUS P8Z68-V PRO (غیر GEN3)
- پردازنده: Intel Core i7-2600K، چهار هسته و هشت رشته
- رم فعلی: 8GB DDR3، شامل دو ماژول 4GB
- هارد فعلی: Western Digital، ظرفیت 500GB، مکانیکی HDD
- سیستم‌عامل: Windows 10 Pro 22H2، نسخه 64 بیتی
- مجازی‌سازی پردازنده: در Task Manager وضعیت Virtualization برابر Enabled است.

## ۲. برنامه ارتقا
- ارتقای RAM به 32GB DDR3، ترجیحاً چهار ماژول 8GB سازگار
- خرید SSD ساتا 2.5 اینچی با ظرفیت حدود 512GB
- مدل‌های پیشنهادی SSD:
  - Kingston KC600 512GB، مدل SKC600/512G
  - Samsung 870 EVO 500GB، مدل MZ-77E500BW
- هارد فعلی فعلاً حفظ شود و پیش از هر تغییر مهم از اطلاعات نسخه پشتیبان تهیه شود.

## ۳. هدف
آماده‌سازی سیستم برای:
- یادگیری Python و کتاب Build an AI Agent from Scratch
- کار با VS Code
- نصب و اجرای Docker
- اجرای n8n و سرویس‌های اتوماسیون
- توسعه پروژه‌های AI Agent و تحلیل اخبار بازار فارکس

## ۴. تصمیم فعلی درباره سیستم‌عامل
فعلاً قرار است Windows حفظ شود و ابزارهای لینوکس از طریق WSL 2 اجرا شوند. برای Docker و پروژه‌های فعلی، در این مرحله نیازی به نصب جداگانه Ubuntu یا Dual Boot نیست.

## ۵. کارهایی که تاکنون برای WSL 2 انجام شده
- دستور `wsl --status` اجرا شد.
- خروجی نشان داد:
  - `Default Version: 2`
  - پیام درخواست فعال‌کردن قابلیت Windows با نام `Virtual Machine Platform`
- سپس PowerShell با دسترسی Administrator اجرا شد و این دستور وارد شد:

```powershell
Enable-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform -All
```

- دستور موفقیت‌آمیز بود و خروجی شامل موارد زیر شد:

```text
Online        : True
RestartNeeded : True
```

- هنگام درخواست راه‌اندازی مجدد، گزینه `N` انتخاب شد؛ بنابراین کامپیوتر هنوز Restart نشده است.

## ۶. قدم بعدی دقیق
۱. ابتدا کارهای باز را ذخیره و کامپیوتر را Restart کن.
۲. پس از ورود به ویندوز، PowerShell را با دسترسی Administrator باز کن.
۳. دستور زیر را اجرا کن:

```powershell
wsl --status
```

۴. خروجی جدید را بررسی کن و برای ادامه بفرست.
۵. سپس وضعیت WSL و نیاز احتمالی به به‌روزرسانی آن را بررسی می‌کنیم و بعد سراغ نصب Docker می‌رویم.

## ۷. نکته مهم
تا این مرحله Docker نصب نشده است. ابتدا باید وضعیت WSL 2 پس از Restart تأیید شود. Windows 10 نیز از اکتبر 2025 از پشتیبانی عمومی خارج شده است؛ بنابراین سازگاری نسخه ویندوز و وضعیت امنیتی آن باید هنگام ادامه کار در نظر گرفته شود.

**نقطه توقف فعلی: کامپیوتر هنوز Restart نشده است.**
