### 4.1 Structured Output

### 4.2 Asynchronous Python

The following concepts have been covered:

- `async def`: Defines an asynchronous function.
- Coroutine: An asynchronous computation represented by a coroutine object when the function is called.
- `await`: Waits for an awaitable operation while allowing other tasks to progress.
- `asyncio.run()`: Runs the asynchronous entry-point function.
- `asyncio.gather()`: Runs multiple awaitables concurrently and collects their results.
- `zip()`: Pairs corresponding elements from iterables.
- `asyncio.Semaphore`: Limits the number of tasks entering a protected asynchronous section.
- `num_retries`: Configures retry attempts in LiteLLM.
- `return_exceptions=True`: Allows exceptions to be returned as results instead of propagating an individual task's failure through `gather()`.

### 4.4 Rate-Limited Concurrent Requests

The next book example introduced concurrency control and retry handling.

The adapted program uses:

`semaphore = asyncio.Semaphore(10)`

The `call_llm()` function places the `acompletion()` call inside an `async with semaphore` block and configures:

`num_retries=3`

The main function creates 100 arithmetic prompts, creates a coroutine for each prompt, and collects results using:

`await asyncio.gather(*tasks, return_exceptions=True)`

Successful results and exceptions are handled separately when displaying the output.

**Test result:** All 100 arithmetic questions returned responses successfully in the observed run.

This confirms that the test completed successfully. Execution time and the actual number of simultaneous API calls have not yet been measured.
